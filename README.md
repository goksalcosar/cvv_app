# CV Uygulaması

Bu proje, Kapadokya Üniversitesi 2023-2024 Eğitim Yılı Bahar Dönemi React dersi vize ödevi için geliştirilmiştir.

## Proje Hakkında

Modern ve responsive bir CV uygulaması. Sol tarafta kişisel bilgiler ve hobiler, sağ tarafta ise iş deneyimi, yetenekler ve eğitim bilgileri yer almaktadır.

## Kullanılan Teknolojiler

- **React**: UI geliştirme için kullanıldı
- **Vite**: Proje altyapısı ve build tool olarak kullanıldı
- **React Icons**: Sosyal medya ve hobi ikonları için kullanıldı

## Proje Yapısı

Proje modüler bir yapıda geliştirilmiş olup, her bir CV bölümü ayrı bir component olarak tasarlanmıştır:

- `ProfileSection`: Profil bilgileri ve iletişim
- `HobbiesSection`: Hobiler ve ilgi alanları
- `ExperienceSection`: İş deneyimi
- `SkillsSection`: Yetenekler
- `EducationSection`: Eğitim bilgileri

## Kurulum

```bash
# Projeyi klonlayın
git clone [repo-url]

# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev
```
